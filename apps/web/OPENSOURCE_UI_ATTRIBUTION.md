# Opensource UI attribution

`src/components/SoftPillButton.tsx` adapts `components/buttons/soft-pill-button.tsx` from [Opensource UI](https://github.com/bidyut10/opensourceui). The source is MIT licensed. The adaptation removes the Next.js path alias and uses this Vite app's class helper and focus color. All business data and graph visuals are BenchWitness code, backed by its API.
