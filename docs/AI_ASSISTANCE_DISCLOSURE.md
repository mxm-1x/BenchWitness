# AI assistance disclosure

BenchWitness was developed during Graph Hacks with assistance from Google Antigravity and OpenAI Codex.

Google Antigravity was used to generate the initial frontend design and site scaffold. OpenAI Codex then worked on making the frontend functional with the API, and assisted with implementation and review across the FastAPI backend, FalkorDB Cypher access, deterministic ML runner and recovery worker, interfaces, integration tests, setup instructions, architecture notes, and milestone documentation. Codex also ran local checks and helped diagnose and fix issues. No paid AI API or hosted model is required by the product; the local typed agent uses deterministic graph tools.

The human participant chose the problem and product direction, supplied the zero-spend and hackathon constraints, set the milestone sequence and acceptance goals, used Antigravity to develop the initial frontend, ran the app, reviewed milestone results, identified issues, and directed corrections. Before submission, the participant should review the final code and demo, confirm this description matches their contribution, and be prepared to explain the graph model, key queries, recovery safeguards, and measured results.

The demo data is generated locally and synthetically. No private, restricted, or paywalled dataset was used.
